# Subagent（同步 task 工具）Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让父 run 经同步 `task` 工具把一个只读子目标委派给一个**工具面受父选择限定**的子 agent，子 agent 跑成一条完整可审计的独立 `domain.Run`（DB 行 + 事件 + 预算 + checkpoint），结果作为工具输出字符串回传父模型；`WORKER_CONCURRENCY=1` 下无死锁。

**Architecture:** 纯后端、零前端改动。核心不变量：子 run 在**父已持有的 worker 槽位内内联驱动**（`RunChild` 不碰 `r.sem`，吃父 `ctx` 做 cancel/deadline 级联）——若走 `Execute` 会死锁。分层（对应 spec §7 包边界，无循环依赖 `subagent → runtime,store,tool,domain`）：
- `runtime.RunChild` = **纯模型循环**（过滤工具 + 同步 drain），返回 `ChildOutcome`，**不碰 DB**。
- `subagent` handler（持 `*store.TaskRepo` + `*runtime.EinoRunner`）= 建子行 + `MarkStarted` + `RunChild` + **子行终态化**（所有 DB 写走 `context.Background()`，dead-ctx-safe）+ 拼工具输出串。
- 递归闸：`filterToolNames(toolNames, depth)` 在 depth≥1 时剔除 `task` + handler `tc.Depth>=1` 双闸。

**Tech Stack:** Go 1.27（`backend/`，Eino ADK v0.9.21，SQLite via modernc）。集成测试 `backend/tests/integration/` + `testutil.Harness`（plain `t.Fatal`，无 testify）。

**Spec:** `docs/superpowers/specs/2026-10-15-subagent-design.md`

**Out of scope（明确不做）:** 异步并行子（fan-out/句柄/父 resume）、写工具子 + 审批冒泡、多级嵌套（depth>1）、`GET /runs/{id}/children` 端点、子成本统计、预算可配置（40% + 命名常量定死）。

## 架构核对（写 plan 时对着真实代码确认，与 spec 的两处 reconcil）

- `EinoRunner`（`runner_eino.go:50-62`）**无 `TaskRepo` 字段**（只有 `modelFactory/registry/executor/checkpoints/instruction/cancels/…`）。故 spec §5 把 `MarkStarted`/终态化放进 `RunChild` 不可实现——**DB 终态化整体移到 `subagent` handler**（它持 `tasks`+`runner`），`RunChild` 只做模型循环并返回 `ChildOutcome`。这与 spec §7「handler 只做拼接 + `subagent` 持 `TaskRepo`」一致，是 spec 的落地细化，非扩大 scope。
- `CreateRun`（`task_repo.go:128`）对 `IdempotencyKey` 用 `nullIfEmpty`（:363）→ 子行空 idem 变 `NULL`；SQLite 唯一索引 `idx_runs_owner_idem` 允许多个 NULL → **多个子行不冲突**，无需给子行造 idem 键。
- `OnEvent`（`runtime.go:35-38`）按 `ev.RunID` 自动落库事件 → 子 drain 复用 `emit`（`runner_eino.go:329`，同时 `out<-ev` + `r.onEvent(ev)`）即**免费持久化子事件**。
- `drain`（`runner_eino.go:259`）是同步阻塞、终态即返回 → 用「`go func(){defer close(out); r.drain(...)}()` + `for ev := range out`」即可同步等待子完成，`ctx` 级联由 drain 内 `case <-ctx.Done()` 处理。
- 共享 `ScriptedModel`（`h.Model`）父/子共用同一 queue（`harness.go:48/59`）→ 集成测试委派成功时按 FIFO 排队（见 Task 4 测试）。

```go
		if err := rows.Scan(&cid, &name, &typ, &notnull, &pkey); err != nil { return false, err }
		if name == col { return true, nil }
	}
	return false, nil
```

```go
package runtime

import (
	"context"
	"rivus-agent-backend/internal/domain"
)

// TaskContext 携带父 run 身份/预算/深度，注入 ctx 让 task 工具能读。
type TaskContext struct {
	OwnerID, ParentRunID, SessionID string
	ParentBudget                    domain.Budget
	Depth                           int // 0=顶层(可 spawn 子)；>=1=子(禁 task)
}

type taskCtxKey struct{}

func WithTaskContext(ctx context.Context, tc TaskContext) context.Context {
	return context.WithValue(ctx, taskCtxKey{}, tc)
}

func TaskContextFrom(ctx context.Context) (TaskContext, bool) {
	tc, ok := ctx.Value(taskCtxKey{}).(TaskContext)
	return tc, ok
}
```

```go
package runtime

// ChildRequest 驱动一个只读子 agent（模型循环）；DB 终态化由 subagent handler 负责。
type ChildRequest struct {
	OwnerID, ChildRunID string
	Goal                string
	ToolNames           []string // 父选的只读子集；nil=全量只读
	Budget              domain.Budget
	Depth               int // 1=子
	CheckpointID        string
}

// ChildOutcome 是 RunChild 的分类结果（不含 DB 写）。
type ChildOutcome struct {
	FinalText    string
	ToolEvidence int
	ModelFailed  bool
	SawApproval  bool
	Cancelled    bool
	Deadline     bool
	PreDrainErr  error
}

// ChildExecutor 由 *EinoRunner 实现（subagent 包依赖此接口，避免 import 具体实现细节）。
type ChildExecutor interface {
	RunChild(ctx context.Context, req ChildRequest) ChildOutcome
}

// CheckpointCleaner 清子 checkpoint（*EinoRunner 已实现 DeleteCheckpointsByRun，runner_eino.go:108）。
// subagent 经此接口引用，避免 import 具体类型之外的依赖。
type CheckpointCleaner interface {
	DeleteCheckpointsByRun(ctx context.Context, runID string)
}

// filterToolNames：toolNames nil→**保持 nil**（全量由 buildAgentFiltered 处理）；否则只保留命中项；depth>=1 剔除 "task"。
func filterToolNames(toolNames []string, depth int) []string {
	if toolNames == nil {
		return nil
	}
	out := make([]string, 0, len(toolNames))
	for _, n := range toolNames {
		if depth >= 1 && n == "task" {
			continue
		}
		out = append(out, n)
	}
	return out
}

// buildAgentFiltered：按 toolNames(+depth 守卫)过滤工具，构建子 agent。
func (r *EinoRunner) buildAgentFiltered(ctx context.Context, runID string, budget domain.Budget,
	approved map[string]bool, toolNames []string, depth int) (*adk.ChatModelAgent, error) {
	base, err := r.modelFactory()
	if err != nil {
		return nil, err
	}
	names := filterToolNames(toolNames, depth) // 注意：nil 表示全量
	var defs []itool.Definition
	if names == nil {
		defs = r.registry.List()
	} else {
		for _, n := range names {
			if d, ok := r.registry.Get(n); ok {
				defs = append(defs, d)
			}
		}
	}
	// 关键：depth>=1 时，全量分支也要剔除 task（父选的 nil 不应让子拿到 task）。用新切片，避免 in-place alias。
	if depth >= 1 {
		kept := make([]itool.Definition, 0, len(defs))
		for _, d := range defs {
			if d.Name != "task" {
				kept = append(kept, d)
			}
		}
		defs = kept
	}
	var tools []tool.BaseTool
	for _, d := range defs {
		d := d
		tools = append(tools, &gatewayTool{def: d, runID: runID, approved: approved,
			executor: r.executor, onNeedApproval: r.needApprovalHandler(runID)})
	}
	withTools, err := base.WithTools(collectInfos(tools))
	if err != nil {
		return nil, err
	}
	maxIter := budget.MaxIterations
	if maxIter <= 0 { maxIter = 12 }
	cfg := &adk.ChatModelAgentConfig{Name: "rivus", Description: "general purpose agent",
		Instruction: r.instruction, Model: withTools, MaxIterations: maxIter}
	cfg.ToolsConfig.Tools = tools
	return adk.NewChatModelAgent(ctx, cfg)
}

// RunChild：同步驱动一个只读子 agent（复用父 ctx 做 cancel/deadline 级联；不碰 r.sem）。
// 只做模型循环 + 分类，DB 终态化交给调用方（subagent handler）。
func (r *EinoRunner) RunChild(ctx context.Context, req ChildRequest) ChildOutcome {
	agent, err := r.buildAgentFiltered(ctx, req.ChildRunID, req.Budget, nil, req.ToolNames, req.Depth)
	if err != nil {
		return ChildOutcome{PreDrainErr: err}
	}
	runner := adk.NewRunner(ctx, adk.RunnerConfig{Agent: agent, EnableStreaming: true, CheckPointStore: r.checkpoints})
	out := make(chan RuntimeEvent, 64)
	r.emit(out, req.ChildRunID, domain.EvtRunStarted, "child run started", "", "") // 子事件含 run.started（经 OnEvent 免费落库）
	iter := runner.Run(ctx, []*schema.Message{schema.UserMessage(req.Goal)})
	go func() { defer close(out); r.drain(ctx, req.ChildRunID, req.CheckpointID, iter, out) }()

	var o ChildOutcome
	for ev := range out {
		switch ev.Type {
		case domain.EvtToolCompleted:
			o.ToolEvidence++
		case domain.EvtModelCompleted:
			o.FinalText = ev.Text
		case domain.EvtModelFailed:
			o.ModelFailed = true
		case domain.EvtRunFinished:
			o.FinalText = ev.Text
		case domain.EvtApprovalRequested:
			o.SawApproval = true
		}
	}
	if o.SawApproval {
		return o
	}
	if errors.Is(ctx.Err(), context.DeadlineExceeded) {
		o.Deadline = true
		return o
	}
	if ctx.Err() == context.Canceled {
		o.Cancelled = true
		return o
	}
	return o
}
```

```go
const taskToolName = "task"

// TaskTool 返回 task 工具的 Definition（ApprovalNever；risk 由子的只读面界定为 read）。
// runner 驱动子模型循环（ChildExecutor）；cleaner 清子 checkpoint（CheckpointCleaner）。
// 装配处二者通常传同一个 *EinoRunner（它同时实现两个接口）。
func TaskTool(reg *itool.Registry, tasks *store.TaskRepo, runner runtime.ChildExecutor, cleaner runtime.CheckpointCleaner) itool.Definition {
	h := NewTaskHandler(reg, tasks, runner, cleaner)
	return itool.Definition{
		Name: taskToolName,
		Description: "Delegate a read-only sub-goal to a child agent; runs synchronously and returns its result.",
		Version: "v1",
		InputSchema: `{"type":"object","properties":{"goal":{"type":"string"},"tools":{"type":"array","items":{"type":"string"}},"max_model_calls":{"type":"integer"},"max_tool_calls":{"type":"integer"},"max_iterations":{"type":"integer"}},"required":["goal"]}`,
		Risk: itool.RiskRead, Approval: itool.ApprovalNever, Idempotent: false, TimeoutMs: 120000, MaxResultBytes: 64*1024,
		Handler: h,
	}
}

type taskIn struct {
	Goal          string   `json:"goal"`
	Tools         []string `json:"tools"`
	MaxModelCalls *int     `json:"max_model_calls"`
	MaxToolCalls  *int     `json:"max_tool_calls"`
	MaxIterations *int     `json:"max_iterations"`

// NewTaskHandler：task 工具的唯一执行入口（父身份/预算/深度经 ctx）。
func NewTaskHandler(reg *itool.Registry, tasks *store.TaskRepo, runner runtime.ChildExecutor, cleaner runtime.CheckpointCleaner) itool.Handler {
	return func(ctx context.Context, args json.RawMessage) (string, error) {
		tc, ok := runtime.TaskContextFrom(ctx)
		if !ok || tc.Depth >= 1 {
			return errOut{"task not available at this depth"}.String(), nil
		}
		var in taskIn
		if err := json.Unmarshal(args, &in); err != nil || strings.TrimSpace(in.Goal) == "" {
			return errOut{"task: invalid goal"}.String(), nil
		}
		// 白名单：每个 name 在 registry 且 ApprovalNever+RiskRead；缺省=全量只读。
		toolNames, err := resolveReadOnlyTools(reg, in.Tools)
		if err != nil {
			return errOut{err.Error()}.String(), nil
		}
		budget := clampChildBudget(tc.ParentBudget, in)
		// 子行落库 + 所有子 DB 写走 context.Background()（dead-ctx-safe；父 cancel/deadline 时 ctx 已死）
		bg := context.Background()
		childID := uuid.NewString()
		if err := tasks.CreateRun(bg, &domain.Run{
			ID: childID, OwnerID: tc.OwnerID, SessionID: tc.SessionID,
			Status: domain.RunQueued, Mode: "react", Goal: in.Goal,
			Budget: budget, ParentRunID: tc.ParentRunID, Attempt: 1,
		}); err != nil {
			return errOut{"task: create child run: " + err.Error()}.String(), nil
		}
		_ = tasks.MarkStarted(bg, tc.OwnerID, childID)
		observability.IncrRunStarted()
		// 模型循环用活 ctx（父 ctx）：父 cancel/deadline 经 drain 级联到子。
		o := runner.RunChild(ctx, runtime.ChildRequest{
			OwnerID: tc.OwnerID, ChildRunID: childID, Goal: in.Goal,
			ToolNames: toolNames, Budget: budget, Depth: tc.Depth + 1,
			CheckpointID: "ckpt_" + childID + "_" + fmt.Sprintf("%d", time.Now().UnixNano()),
		})
		switch {
		case o.PreDrainErr != nil:
			finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunFailed, "runner_error", o.PreDrainErr.Error(), false, cleaner)
			return out(childID, "failed", "", "runner_error: "+o.PreDrainErr.Error()).String(), nil
		case o.SawApproval:
			finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunFailed, "child_needs_approval", "", false, cleaner)
			return out(childID, "failed", "", "child hit approval (unsupported for read-only child in v1)").String(), nil
		case o.Deadline:
			finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunTimedOut, "timed_out", "child exceeded budget", false, cleaner)
			return out(childID, "timed_out", o.FinalText, "").String(), nil
		case o.Cancelled:
			finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunCancelled, "cancelled", "parent cancelled", false, cleaner)
			return out(childID, "cancelled", o.FinalText, "cancelled").String(), nil
		case o.ModelFailed && o.ToolEvidence == 0:
			finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunFailed, "model_failed", "child model failed, no tool evidence", false, cleaner)
			return out(childID, "failed", "", "model_failed").String(), nil
		case strings.TrimSpace(o.FinalText) == "" && o.ToolEvidence == 0:
			// 空结果守卫：无文本且无工具证据 → 失败，绝不判 succeeded。
			finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunFailed, "empty_result", "child produced no result or evidence", false, cleaner)
			return out(childID, "failed", "", "empty_result").String(), nil
		default:
			rep := runtime.Verify(nil, o.FinalText, o.ToolEvidence) // 无 success_criteria → Passed 恒真
			rb, _ := json.Marshal(map[string]any{"passed": rep.Passed, "evidence": o.FinalText})
			_ = tasks.SetResult(bg, childID, string(rb))
			if rep.Passed {
				finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunSucceeded, "", "", true, cleaner)
			} else {
				finalizeChild(bg, tasks, tc.OwnerID, childID, domain.RunFailed, "verification_failed", "", false, cleaner)
			}
			return out(childID, stringOfStatus(rep.Passed), o.FinalText, "").String(), nil
		}
	}
}

	observability.IncrRunFinished(passed)
	cleaner.DeleteCheckpointsByRun(bg, id)
}
```

```go
func resolveReadOnlyTools(reg *itool.Registry, names []string) ([]string, error) {
	if len(names) == 0 {
		// 缺省 = registry 里全部 ApprovalNever+RiskRead（含 task 本身；depth 守卫会剔除）
		var out []string
		for _, d := range reg.List() {
			if d.Approval == itool.ApprovalNever && d.Risk == itool.RiskRead {
				out = append(out, d.Name)
			}
		}
		return out, nil

	res := make([]string, 0, len(names))

		}

	}
```

```go
const (
	childBudgetFrac         = 0.40
	childCapModelCalls      = 20
	childCapToolCalls       = 30
	childCapIterations      = 10
	childCapDurationSeconds = 180
	childCapOutputBytes     = 8 * 1024
)

func clampChildBudget(parent domain.Budget, in taskIn) domain.Budget {
	frac := func(v int) int {
		if v <= 0 { return 0 }
		return int(float64(v) * childBudgetFrac)
	}
	capTo := func(v, cap int) int { if v > cap { return cap }; return v }
	mmc := capTo(frac(parent.MaxModelCalls), childCapModelCalls)
	mtc := capTo(frac(parent.MaxToolCalls), childCapToolCalls)
	mi := capTo(frac(parent.MaxIterations), childCapIterations)
	md := capTo(frac(parent.MaxDurationSeconds), childCapDurationSeconds)
	mo := capTo(frac(parent.MaxOutputBytes), childCapOutputBytes)
	if in.MaxModelCalls != nil { mmc = capTo(*in.MaxModelCalls, childCapModelCalls) }
	if in.MaxToolCalls != nil { mtc = capTo(*in.MaxToolCalls, childCapToolCalls) }
	if in.MaxIterations != nil { mi = capTo(*in.MaxIterations, childCapIterations) }
	// 缺省(请求 0)则取 40%；请求值则收紧到 min(请求, 上限)
	return domain.Budget{MaxModelCalls: mmc, MaxToolCalls: mtc, MaxIterations: mi,
		MaxDurationSeconds: md, MaxOutputBytes: mo}
}
```

## 关键实现注记（防回归）

- **`RunChild` 不碰 `r.sem`**（`Execute` 的 `select { case r.sem <- struct{}{} }` 是死锁源；`RunChild` 是被 handler 内联调用的方法，天然不抢槽位）。这是核心不变量，勿改。
- **子行 DB 写全用 `context.Background()`**：父 cancel/deadline 时 `ctx` 已死，`database/sql` 会短路死 ctx 的写（no-op）→ 子行卡死。故 `MarkStarted`/`UpdateStatus`/`SetResult`/清 checkpoint 全走 `bg`。
- **`RunChild` 用活 `ctx`（父 ctx）跑模型循环**：父 cancel/deadline 经 `drain` 的 `case <-ctx.Done()` 级联到子，`ctx.Err()` 分类出 cancel vs deadline。
- **无 double-finalization**：`RunChild` 只返回 `ChildOutcome`（不写 DB）；子行终态化**只在 handler** 做；父 `run()` 只 finalize 父。
- **递归闸双保险**：`filterToolNames`/全量分支在 depth≥1 剔除 `task` + handler `tc.Depth>=1` 拒绝。子拿不到 `task`。
- **`CheckpointCleaner`**：`*EinoRunner.DeleteCheckpointsByRun`（`runner_eino.go:118`）复用清子 checkpoint；`subagent` 经 `runtime` 暴露的小接口引用，不 import 具体类型之外的东西。
