# CI Gate Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a single GitHub Actions workflow that gates pushes and PRs on backend and frontend builds plus tests.

**Architecture:** One file `.github/workflows/ci.yml` with two parallel jobs (`backend`, `frontend`), each running in its subdirectory. No changes to application code. Verification is pushing a branch and watching the checks turn green (plus a deliberate local YAML sanity check).

**Tech Stack:** GitHub Actions, `actions/setup-go`, `actions/setup-node`, Go toolchain, npm.

Spec: `docs/superpowers/specs/2026-10-10-ci-design.md`.

---

## Chunk 1: Workflow file

### Task 1: Create ci.yml and validate it

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Write the workflow file**

```yaml
name: ci

on:
  push:
  pull_request:

jobs:
  backend:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: backend
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: '1.27'
          cache: true
      - run: go build ./...
      - run: go vet ./...
      - run: go test ./... -count=1

  frontend:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: frontend
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: npm
          cache-dependency-path: frontend/package-lock.json
      - run: npm ci
      - run: npx tsc --noEmit
      - run: npm test -- --run
      - run: npx vite build
```

- [ ] **Step 2: Validate YAML parses locally**

Run: `python3 -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml')); print('YAML OK')"`
Expected: `YAML OK` (if pyyaml missing: `pip install pyyaml` first, or eyeball the indentation)

- [ ] **Step 3: Mirror-verify each command already passes locally**

Run: `cd backend && go build ./... && go vet ./... && go test ./... -count=1 2>&1 | tail -n 3`
Expected: all `ok`

Run: `cd frontend && npm test -- --run 2>&1 | grep -E "Test Files|Tests "`
Expected: `8+ passed` files/tests (count may grow; zero failures is the gate)

- [ ] **Step 4: Commit**

```bash
git add .github/workflows/ci.yml
git commit -m "ci: gate pushes and PRs on backend and frontend checks"
```

- [ ] **Step 5: Push a branch and confirm green checks (user or maintainer runs this)**

```bash
git push -u origin <branch>
```

Expected: both `backend` and `frontend` jobs green on the Actions tab. If `npm ci` fails on a fresh runner (lockfile drift), run `npm install` locally, commit the updated `frontend/package-lock.json`, and re-push.
