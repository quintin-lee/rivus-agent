# CI 门禁设计文档

- 文档版本：v1.0
- 日期：2026-10-10
- 目标：push/PR 自动跑前后端构建与测试，失败合入前拦截

---

## 1. 决策

- 方案：单 workflow 双 job（A），不按路径拆分。
- 触发：`push`（任意分支）+ `pull_request`。
- 版本：Go `1.27`（对齐 `backend/go.mod`），Node `22`（对齐 `frontend/Dockerfile`），均开依赖缓存。

## 2. Job 步骤

backend job（工作目录 `backend/`）：

1. checkout → setup-go（cache）。
2. `go build ./...`。
3. `go vet ./...`。
4. `go test ./... -count=1`。

frontend job（工作目录 `frontend/`）：

1. checkout → setup-node（cache npm）。
2. `npm ci`（依赖 `package-lock.json`，已在库）。
3. `tsc --noEmit`。
4. `npm test -- --run`。
5. `npx vite build`。

任一步失败则 job 红，PR 不可合入（分支保护规则由仓库管理员另行开启，不在本次范围）。

## 3. 非目标

- 按路径过滤触发；Docker 镜像构建推送；分支保护规则配置；覆盖率上报。
